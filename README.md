# redisnake

Toy game to study distributed computation and Redis.

## How to run the application

First, install dependencies:

```bash
bun install
```

After, run the client and the server.

### Client

```bash
cd packages/client
bun run index.ts
```

### Server

```bash
cd packages/server
bun run index.ts
```

## How to run tests

```bash
bun test
```
